Trilhas de Andaluria

Primeira configuração

  1. Entre em developer.spotify.com/dashboard com a sua conta e crie um app.
  2. Em Redirect URIs, cole exatamente este endereço:
  3. Marque a opção Web API e salve.
  4. Copie o Client ID do app e cole abaixo.

Conectar

Toque para autorizar este painel a controlar a reprodução do seu Spotify.

Cenas

Uma cena por linha, no formato Nome da cena | música. A música pode ser um texto de busca ou um link de faixa do Spotify.

Corte do loop

Pula o começo e o fim de cada faixa, onde a música costuma estar baixa. Em segundos; use 0 para não cortar. Para uma cena específica, acrescente um terceiro campo: Nome | música | 10-20 (início-fim).
